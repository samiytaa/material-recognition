# Tab4 规则管理使用指南

## 🎯 功能概述

Tab4 提供了完整的文件名解析规则管理功能，包括：
- 男主映射管理
- 密探名映射管理
- 分类映射管理（户外、户内、地板）
- 归属规则管理
- 规则测试功能
- 规则文档查看

---

## 📚 快速入门

### 1. 点击「规则文档」按钮
- 查看完整的文件名解析规则说明
- 包含可视化示例和流程图
- 了解各种文件名格式的解析方式

### 2. 点击「测试解析」按钮
- 输入文件名（如 `icon_s1_sc_jianzhu_1001.png`）
- 实时查看解析结果
- 验证显示名、分类、归属等信息

### 3. 修改规则
1. 选择要修改的规则类型标签
2. 点击「新增」或「编辑」按钮
3. 填写或修改映射关系
4. 保存后，**记得在 Tab1 点击「重新解析」**

---

## 🔧 操作说明

### 查看规则文档
1. 点击右上角「规则文档」按钮
2. 浏览完整的解析规则说明
3. 查看各种文件名格式示例

### 测试文件名解析
1. 点击「测试解析」按钮
2. 输入文件名（可选择常用示例）
3. 查看详细的解析结果

### 新增映射规则
1. 选择对应的规则类型标签
2. 点击「新增」按钮
3. 填写键（代码/拼音）和值（中文名）
4. 点击保存按钮

### 编辑映射规则
1. 找到要修改的条目
2. 点击「编辑」按钮
3. 修改键或值
4. 点击保存按钮

### 删除映射规则
1. 找到要删除的条目
2. 点击「删除」按钮
3. 确认删除操作

### 导出规则
1. 点击「导出」按钮
2. 自动下载 JSON 文件（包含所有规则）
3. 妥善保管备份文件

### 导入规则
1. 点击「导入」按钮
2. 选择之前导出的 JSON 文件
3. 规则将被加载

### 重置规则
1. 点击「重置」按钮
2. 确认操作
3. 所有规则恢复为系统默认值

---

## ⚠️ 重要提示

### 修改规则后必须重新解析
修改规则后，已经导入的图片不会自动更新显示名。**必须在 Tab1 点击「重新解析」按钮**，才能应用新规则到所有图片。

### 规则修改流程
```
Tab4 修改规则 → 保存 → Tab1 点击「重新解析」 → 生效
```

### 定期备份规则
建议定期导出规则备份，避免误操作导致规则丢失。

## 📖 规则类型说明

### 男主映射
- 用途：将文件名中的英文代码转换为男主中文名
- 示例：`sc` → `孙策`
- 应用场景：家具、互动道具、装饰等

### 密探名映射
- 用途：将文件名中的拼音转换为密探中文名
- 示例：`sunfu` → `孙辅`
- 应用场景：密探头像、密探相关道具

### 户外分类
- 用途：将分类代码转换为户外家具分类名
- 示例：`jianzhu` → `建筑`
- 应用场景：户外家具识别

### 户内分类
- 用途：将分类代码转换为户内家具分类名
- 示例：`qiju` → `起居`
- 应用场景：户内家具识别

### 地板分类
- 用途：将分类代码转换为地板分类名
- 示例：`diban` → `地板`
- 应用场景：地板家具识别

### 归属规则
- 用途：定义每个分类如何提取归属信息
- 包含：归属类型（男主/密探/无/混合）、提取方式
- 示例：`建筑` 分类 → 归属类型为男主，从家具格式段提取
