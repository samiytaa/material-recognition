# 快速参考

## PropItem 结构速查

```typescript
PropItem {
  name: "文件名.png"
  displayName: "刘辩-起居"
  image: "base64..."
  
  classification: {
    type: "furniture" | "other"
    category: "起居"
    categoryPath: ["家具", "自由装修", "户内", "起居"]
  }
  
  ownership: {
    type: "male_lead" | "spy" | "none"
    name: "刘辩"
    code: "lb"
  }
}
```

## 三大配置文件

| 文件 | 作用 | 编辑方式 |
|------|------|---------|
| parseConfig.json | 文件名→人名/分类映射 | Tab4前5个标签 |
| categoryConfig.json | UI分类树结构 | 手动编辑 |
| categoryOwnershipRules.json | 分类→归属规则 | Tab4归属规则标签 |

## 解析三步骤

```
1. 识别分类 → "起居"
2. 识别归属 → "刘辩"（根据分类规则）
3. 生成名称 → "刘辩-起居"
```

## 归属类型

| 类型 | 颜色 | 用途 |
|------|------|------|
| male_lead | 🔴 红 | 男主专属 |
| spy | 🔵 蓝 | 密探专属 |
| none | ⚫ 灰 | 通用道具 |
| mixed | 🟡 金 | 可能是男主或密探 |

## 提取方式

| 方式 | 示例 |
|------|------|
| segments | icon_nz_**lb**_001 → 刘辩 |
| ccl_code | icon_ccl_**1**001 → 刘辩 |
| component_code | icon_component_**1**1001 → 刘辩 |
| furniture_segment | icon_s1_**lb**_qiju_1 → 刘辩 |
| avatar_pinyin | icon_**achan**_s → 阿蝉 |

## Tab1 筛选组合

```
分类筛选（树形）
    ↓
归属筛选（类型+人名）
    ↓
关键词搜索
    ↓
最终结果
```

## 常用操作

### 添加新男主
1. Tab4 → 男主映射
2. 新增：`xm` → `新名`
3. 自动生效

### 添加新分类
1. 编辑 categoryConfig.json（手动）
2. Tab4 → 归属规则 → 新增规则
3. 刷新页面

### 修改归属规则
1. Tab4 → 归属规则
2. 找到分类 → 编辑
3. 修改归属类型或提取方式

## 数据存储

- **规则** → localStorage `customRulesData`
- **道具** → localStorage `savedProps`
- **修改后** → 自动保存 + 实时生效

## 调试技巧

### 查看解析结果
Tab1 → 上传图片 → 右侧预览面板

### 测试规则
1. 修改Tab4规则
2. Tab1点击"重新解析"
3. 查看日志和预览

### 导出调试
Tab1 → 导出JSON → 查看完整解析数据
