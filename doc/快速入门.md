# 📚 文件名解析 - 快速入门

## 🎯 核心概念

系统会自动读取图片文件名，识别其中的信息，生成中文显示名和分类。

**核心原理：** 文件名按下划线 `_` 分段，不同段代表不同的信息。

---

## 🔍 5分钟快速理解

### 1️⃣ 家具类（最常见）

```
文件名：icon_s1_sc_jianzhu_1001.png
       ↓    ↓  ↓    ↓       ↓
      前缀 季度 男主 分类码   编号

解析结果：孙策-建筑
```

**规则：**
- `icon_s数字` = 家具前缀
- `sc` = 男主代码（查「男主映射」表 → 孙策）
- `jianzhu` = 分类代码（查「户外分类」表 → 建筑）
- 最后的数字 = 编号

### 2️⃣ 密探头像

```
文件名：icon_sunfu_s.png
       ↓     ↓     ↓
      前缀  拼音   标记

解析结果：密探头像-孙辅
```

**规则：**
- 以 `_s` 结尾 = 密探头像
- `sunfu` = 密探拼音（查「密探名映射」表 → 孙辅）

### 3️⃣ 初见日家具

```
文件名：icon_s1_fd_lb_qiju_2001.png
       ↓    ↓  ↓  ↓   ↓     ↓
      前缀 季度FD 男主 分类  编号

解析结果：初见日-刘辩-起居
```

**规则：**
- `fd` = 初见日标记
- `lb` = 刘辩
- `qiju` = 起居（查「户内分类」表）

## 🔧 如何修改规则

### 方法一：Tab4 可视化管理
1. 进入 **Tab4「规则管理」**
2. 选择要修改的规则类型（男主映射、密探名映射等）
3. 点击「编辑」或「新增」
4. 保存后，在 **Tab1 点击「重新解析」** 应用新规则

### 方法二：导入JSON
1. 点击「导出」备份当前规则
2. 用文本编辑器修改 JSON 文件
3. 点击「导入」加载修改后的规则
4. 在 Tab1 点击「重新解析」

---

## 🧪 测试解析功能

在 Tab4 中点击「测试解析」按钮：

1. 输入文件名（如 `icon_s1_sc_jianzhu_1001.png`）
2. 点击「解析」查看结果
3. 查看显示名、分类、归属等信息

**常用测试示例：**
- `icon_s1_sc_jianzhu_1001.png` → 孙策-建筑
- `icon_sunfu_s.png` → 密探头像-孙辅
- `icon_s1_fd_lb_qiju_2001.png` → 初见日-刘辩-起居

## ❓ 常见问题

### Q1：为什么修改规则后没生效？
**A：** 需要在 **Tab1 点击「重新解析」按钮**，系统才会用新规则重新解析所有图片。

### Q2：`all` 是什么意思？
**A：** 代表公用家具，不属于特定男主。  
例：`icon_s1_all_diban_3001.png` → 地板（无归属）

### Q3：文件名不符合格式会怎样？
**A：** 会被归类为「其他」，显示名为原文件名。

### Q4：可以添加新的男主吗？
**A：** 可以！在 Tab4 → 男主映射 → 新增，填写代码和中文名即可。

## 💡 最佳实践

1. **定期备份规则：** Tab4 → 导出 → 保存JSON文件
2. **测试后应用：** 修改规则后先用「测试解析」验证
3. **保持命名规范：** 文件名使用下划线分隔，避免特殊字符
4. **查看完整文档：** 点击 Tab4 的「规则文档」按钮
